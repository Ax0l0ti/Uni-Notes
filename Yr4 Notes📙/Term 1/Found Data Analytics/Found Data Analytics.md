### Coursework 30% vs 70% Examed
- CW1 - Foundations of Computational Data Analytics Coursework (30%)
	**Details** - The coursework will consist of developing computer programs to solve practical problems in computational data analytics. Study time: 12 hours.
- Exam - Foundations of Computational Data Analytics Exam (70%)
	**Details** - Written 2h exam covering the entire module content, timetabled in January. Answerbook Pink (12 page) Students may use a calculator. Study time: 30 hours.

### Course Description

> [!info]+  Course Description
> Course Description copied from [Module Catalogue](https://courses.warwick.ac.uk/modules/2026/CS950-10)

|                        | Content |
| ---------------------- | ------- |
| **Learning Outcomes:** | • Apply data cleaning, preprocessing, and quality assessment techniques to prepare datasets for analysis.<br>• Perform exploratory data analysis and visualisation to uncover patterns, anomalies, and structural insights.<br>• Implement methods for data integration, dimensionality reduction, and feature projection.<br>• Utilise scalable tools and frameworks to analyse and process large datasets. |
| **Synopsis:**          | This module introduces basic concepts and techniques for data analysis with diverse types, including tabular, text, time series, and geospatial data. Students will gain practical skills in data cleaning, dimensionality reduction, visualisation, and exploratory analysis, as well as methods and algorithms for managing and analysing real-world datasets efficiently. It serves as a taster for students considering further study in the Computational Data Analytics module. |
| **Content:**           | • Overview of common data modalities: tabular, JSON, time series, text, networks, and geospatial data<br>• Data cleaning and preprocessing: standardisation, type casting, outlier detection<br>• Exploratory data analysis: descriptive statistics, pattern discovery<br>• Improving data quality: handling missing data, noise filtering, class balancing<br>• Dimensionality reduction: feature projection, embeddings, variance preservation<br>• Data partitioning and sampling: train-test splits, cross-validation, stratified sampling<br>• Data visualisation: matplotlib, seaborn, ggplot2, t-SNE, and geospatial mapping<br>• Correlation and dependency analysis: covariance, mutual information, partial correlation<br>• Scalable data analysis: 5 Vs, stream processing, MongoDB, PySpark, TensorFlow, cloud computing, data lakes and warehousing |
