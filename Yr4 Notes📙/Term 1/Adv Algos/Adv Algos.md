### Course Description

> [!info]+  Course Description
> Course Description copied from [Module Catalogue](https://courses.warwick.ac.uk/modules/2026/CS940-15)
> 
|                        | Content |
| ---------------------- | ------- |
| **Learning Outcomes:** | • Systematic understanding of algorithms, and a critical awareness of time complexities.<br>• Comprehensive understanding of typical algorithmic techniques and data structures.<br>• Conceptual understanding enabling critical assessments of advantages and disadvantages of algorithmic solutions for new problems.<br>• Knowledge of Python programming at a high standard |
| **Synopsis:**          | The aim of the module is to make students more competent programmers and to expose students to different fundamental data structures and algorithmic techniques, to illustrate how choices of data structures and algorithms can impact performance and memory requirements. |
| **Content:**           | • Foundations of Python programming language<br>• Performance and asymptotic runtime/complexity<br>• Data structures such as stacks and queues, trees, hash maps<br>• Algorithmic techniques such as recursion, divide and conquer and dynamic programming<br>• Parallelisation |
