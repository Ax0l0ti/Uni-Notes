### Course Description

> [!info]+  Course Description
> Course Description copied from [Module Catalogue](https://courses.warwick.ac.uk/modules/2026/CS942-15)
> 
|                        | Content |
| ---------------------- | ------- |
| **Learning Outcomes:** | • Apply concepts and techniques from optimization and probability theory to a broad range of computational problems including algorithm design, data analysis, and statistical modelling.<br>• Develop abstract mathematical models for real-world systems and formally analyse them using suitable mathematical techniques.<br>• Solve real-world problems and communicate their solutions in a rigorous manner. |
| **Synopsis:**          | The aim of this module will be to introduce mathematical concepts and techniques from probability theory and optimisation that are fundamental to many modern computing applications and are necessary for more advanced topics in computer science. The module will blend theory with examples to illustrate how mathematical methods can be applied to solve real-life computing problems. |
| **Content:**           | • Probability:<br>• Measurable Sets, Axioms of Probability, Conditional Probability, Bayes Theorem<br>• Random Variables, common distributions, expectation, moments, generating functions, probabilistic inequalities<br>• Jointly distributed random variables, covariance, correlation, conditional expectations, independence, laws of large numbers, central limit theorem<br>• Markov chains, statistical estimation, hypothesis testing<br>• Optimisation:<br>• Introduction to mathematical optimization, linear, non-linear, and convex optimization<br>• Convex sets, convex functions, Duality, Optimality Conditions<br>• Gradient descent, stochastic gradient descent, Newton’s method, Simplex Method |
