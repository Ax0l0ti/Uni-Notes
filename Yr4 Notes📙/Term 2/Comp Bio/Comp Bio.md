### Course Description

> [!info]+  Course Description
> Course Description copied from [Module Catalogue](https://courses.warwick.ac.uk/modules/2026/CS904-15)
> 
|                        | Content |
| ---------------------- | ------- |
| **Learning Outcomes:** | • Have an understanding of how tissue slides are imaged with high throughput<br>• Have a basic grasp of fundamental molecular biology concepts as relevant to this module<br>• Understand some basic and commonly used algorithms in bioinformatics<br>• Know algorithms to compute sequence alignments and how these are applied in current research<br>• Understand basic problems in the processing and analysis of tissue images and some standard solutions to those<br>• Be able to apply image analysis and machine learning to real-world computational pathology problems<br>• Understand principles of fluorescence microscopy and image-based modelling of single cell dynamics<br>• Know how to apply different mathematical techniques for modelling cellular dynamics |
| **Synopsis:**          | The module will cover topics on the acquisition of and analysis of large-scale data generated in biomedical sciences, particularly DNA/RNA sequences, live cell microscopy and multi-gigapixel pathology images. Students will be introduced to how these data are acquired, modern machine learning methods to process the data, and computational modelling approaches to help us better understand the complex phenomena underpinning biological processes. The module will be taught following an "algorithmic approach," demonstrating that addressing problems in computational biology requires a diverse range of theoretical concepts and algorithms, making it an exciting and rapidly evolving field for computer scientists. The students will learn using deep learning models for analysis of multi-gigapixel images. Therefore, basic understanding of image processing concepts will be required. |
| **Content:**           | • Molecular biology fundamentals;<br>• Sequence alignments;<br>• Phylogenetic Trees;<br>• Dimensionality reduction and clustering;<br>• Live cell microscopy fundamentals;<br>• Image based modelling of single cell dynamics;<br>• Overview of mathematical modelling techniques and their application: Ordinary differential equations, stochastic differential equations, Monte Carlo methods<br>• Introduction to tissue imaging and computational pathology;<br>• Whole-slide image (WSI) handling<br>• WSI processing using machine learning and deep learning algorithms;<br>• Recognising various kinds of cells in cancerous WSIs;<br>• Advanced research topics in computational biology; |
