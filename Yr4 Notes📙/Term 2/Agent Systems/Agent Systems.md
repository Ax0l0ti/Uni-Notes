### Course Description

> [!info]+  Course Description
> Course Description copied from [Module Catalogue](https://courses.warwick.ac.uk/modules/2026/CS924-15)
> 
|                        | Content |
| ---------------------- | ------- |
| **Learning Outcomes:** | • Students will learn the basic methodologies for the design and the analysis of multi-agent systems, in competitive and cooperative interaction, both from the theoretical and the practical point of view. |
| **Synopsis:**          | Agent-based systems offer a new paradigm for computer science, based around a strong theoretical foundation and with a large number of practical deployed applications.<br><br>Module web page |
| **Content:**           | • Overview: definitions of agents, distributed AI and agents, intelligent agents, multi-agent systems, cooperation, agent application areas.<br>• Logic-based agents: actions, goals and strategies.<br>• Decision-making agents: expected utility and decisions.<br>• Game-theoretic agents: equilibria and rationality.<br>• Learning-agents: Markov Decision Processes, policy approximation and opponent modelling.<br>• Social-agents: Cooperative decision-making, matching and networks. |
